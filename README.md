# Метод блочной сортировки
Даны три файла вещественных чисел из интервала от 0 до 1, состоящих из 100, 1000 и 10000 чисел. Программа выполняет сортировку данных с помощью метода блочной сортировки.

Программа считывает числа из файла и помещает их в массив. Числа делятся на 10 блоков по цифре последнего разряда. После чего разделение на блоки происходит с каждым разрядом.

В консоль выводится неотсортированный массив, отсортированный и время выполнения алгоритма.
